Adafruit ESP32-S2 Feather

Use this only for the ESP32-S2 Feather.

Use desktop Chrome or Edge with Web Serial support. This page must be opened over HTTPS or localhost.

After flashing

  1. Reboot the board after the installer finishes.
  2. Look for HOLDEN-LORA-C3-xxxxxx or HOLDEN-LORA-S2-xxxxxx.
  3. Connect with password repeater-setup.
  4. Open http://192.168.4.1.
  5. Then connect/configure the DX-LR20. The setup AP now starts before radio initialization.

If the DX-LR20 is missing or wired wrong, the setup Wi-Fi should still remain visible.

Always attach an antenna before allowing the DX-LR20 to transmit.
