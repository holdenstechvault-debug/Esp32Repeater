Holden LoRa Repeater

Browser flasher for the grandparents' XIAO ESP32-C3 + DX-LR20 repeater.

Flash firmware

Plug the XIAO ESP32-C3 into USB, use Chrome or Edge, then click Install.

Use desktop Chrome or Edge with Web Serial support. This page must be opened over HTTPS or localhost.

After flashing

  1. Connect the DX-LR20 and its antenna before transmitting.
  2. Power/reboot the XIAO.
  3. Join Wi-Fi HOLDEN-LORA-xxxxxx with password repeater-setup.
  4. Open http://192.168.4.1.
  5. Copy the generated 256-bit key and use that same key on the home and girlfriend endpoints.

The radio pin assignments are editable in the setup page, so the firmware does not permanently lock you to one adapter-board header mapping.
