Holden RF Repeater + Messenger

Flash the two repeater boards and either messenger endpoint from Chrome or Edge.

Repeater boards

XIAO ESP32-C3 + DX-LR20

Repeater output side. Authenticates endpoint packets and retransmits them as LoRa.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS.

Adafruit ESP32-S2 Feather + CC1101

Repeater receive side. The setup Wi-Fi now starts before UART, SPI, Preferences or CC1101 initialization.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS.

Messenger endpoints

Heltec WiFi LoRa 32 V3

Uses the built-in SX1262. Sends FSK to the repeater and listens for the authenticated LoRa repeat.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS.

Home XIAO ESP32-C3 + DX-LR20

Browser messenger for the DX-LR20 node at home. Uses the same D0-D5 / D8-D10 radio wiring.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS.

After flashing

  1. Repeater C3 Wi-Fi: HOLDEN-LORA-C3-xxxxxx, password repeater-setup, then open http://192.168.4.1.
  2. Repeater S2 Wi-Fi: HOLDEN-LORA-S2-xxxxxx, same password and address. Its AP starts before any CC1101 or UART work.
  3. Messenger Wi-Fi: HOLDEN-MSG-HELTEC-xxxxxx or HOLDEN-MSG-HOME-xxxxxx, password holden-messenger, then open http://192.168.4.1.
  4. Copy the C3 repeater's Shared 256-bit key and Network ID into both messenger endpoints.
  5. Set the messenger FSK uplink frequency to the same value as the S2 CC1101. Default is 915 MHz and can be changed from the setup pages.

Repeated-only display: endpoint message lists only accept the C3's authenticated HL LoRa repeat envelope. Direct FSK packets are never added to the message list.

Attach the correct antenna before transmitting. Make sure the CC1101 and DX-LR20 hardware/antennas support the frequency you configure.
