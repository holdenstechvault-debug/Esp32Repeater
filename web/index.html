Holden RF Repeater + Messenger

Flash the repeater boards and the Heltec V3 endpoint from Chrome or Edge. The home DX-LR20 connects directly to the computer through its USB-C interface and does not need an ESP32 firmware flash.

Repeater boards

XIAO ESP32-C3 + DX-LR20

Repeater output side. Authenticates endpoint packets and retransmits them as LoRa.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS.

Adafruit ESP32-S2 Feather + CC1101

Repeater receive side. The setup Wi-Fi starts before UART, SPI, Preferences or CC1101 initialization.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS.

Messenger endpoints

Heltec WiFi LoRa 32 V3

Uses the built-in SX1262. Your phone connects to the Heltec's Wi-Fi messenger. The SX1262 sends FSK to the repeater and listens for the authenticated LoRa repeat.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS.

Home computer + DX-LR20 over USB-C

No XIAO ESP32-C3 is used at home. The home DX-LR20 plugs into the computer through the USB-C interface/adapter and is controlled by desktop messenger software.

No firmware flasher is required for this endpoint.

The desktop software will receive the repeater's LoRa output, verify the authenticated HL repeat frame, and only then show the message.

After flashing

  1. Repeater C3 Wi-Fi: HOLDEN-LORA-C3-xxxxxx, password repeater-setup, then open http://192.168.4.1.
  2. Repeater S2 Wi-Fi: HOLDEN-LORA-S2-xxxxxx, same password and address.
  3. Heltec messenger Wi-Fi: HOLDEN-MSG-HELTEC-xxxxxx, password holden-messenger, then open http://192.168.4.1.
  4. Copy the C3 repeater's Shared 256-bit key and Network ID into the Heltec messenger and the home desktop messenger.
  5. Set the Heltec FSK uplink frequency to the same value as the S2 CC1101. Set the home DX-LR20 LoRa settings to the same values as the repeater C3 output.

Repeated-only display: the receiving messenger accepts only the C3's authenticated HL LoRa repeat envelope. Raw or unrelated RF packets are not shown as messages.

Attach the correct antenna before transmitting. Make sure the CC1101 and DX-LR20 hardware/antennas support the frequency you configure.
